# Documentation of log2csv

The `docs/` folder contains all of the documentation for the `log2csv` program.

It is separated into documents that explain how to use the program and documents that explain how it implemented.
These are separated into two different subfolders:
- `usage/` - How to use the program
- `implementation/` - How the program was implemented

----

If you cannot find what you are looking for, then please create an issue. :smile:
